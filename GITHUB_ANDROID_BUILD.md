# NEON CAT: STATION X — Build APK in GitHub Actions

1. Create/sign in to GitHub.
2. Create a new repository, e.g. `NeonCat-StationX`.
3. Upload the contents of this project ZIP to the repository root.
4. Open **Actions**.
5. Select **Build NEON CAT Android APK**.
6. Tap **Run workflow**.
7. Wait for the workflow to finish.
8. Open the completed run and download **NEON_CAT_STATION_X-APK**.
9. Extract it and install `NEON_CAT_STATION_X.apk` on Android.

This workflow creates a debug/test APK. A Google Play release will later use a release keystore and AAB.
